## 任务：对接 Qwen（百炼 Token Plan）文生图/文生视频接口

### 方案
- 仿 Ark 媒体转发模板（`service/ark_media.go` + `handler/ark_media.go`），新增 Qwen 版：`service/qwen_media.go` + `handler/qwen_media.go`，路由 `gateway.go` 三个 switch（images/videoGeneration/videoStatus）加 `case PlatformQwen`。
- 上游走 DashScope 原生异步任务协议（凯哥给的 Token Plan 示例）：提交 `POST {origin}/api/v1/services/aigc/text2image|video-generation/...`（`X-DashScope-Async: enable`），查询 `GET {origin}/api/v1/tasks/{task_id}`。
- **origin 提取**：账号 base_url 是 OpenAI 兼容形态（`.../compatible-mode/v1`），`qwenMediaAPIOrigin()` 只取 scheme://host 拼 `/api/v1/...`；配 dashscope.aliyuncs.com 也自动兼容。
- **图片 = 同步体验**：提交后服务端轮询（2s 间隔/110s 超时），SUCCEEDED 后归一化成 OpenAI images 响应 `{created, data:[{url}]}`；超时 504 且 message 里带 task_id 提示可自查。
- **视频 = 异步**：提交即返回上游响应（含 output.task_id），客户端 `GET /v1/videos/{task_id}` 查状态（与 Ark 形态一致），粘性会话 `qwen-media:` 前缀绑定提交账号。
- **请求体转换**：对外收扁平 OpenAI-ish（model/prompt/size/n/resolution/ratio/duration/img_url），内部组装 DashScope {model,input,parameters}；客户端直接发 DashScope 原生格式（含 input 对象）则原样透传。size 自动 1024x1024→1024*1024。
- 计费字段：图片 ImageCount（结果数，兜底 n/1）+ ImageSize 归一；视频 VideoCount=1 + Duration/Resolution 归一。handler 层 failover/池模式重试/分组图片权限/内容审核全复用 ark 路径。

### 改动文件
- 新增 `backend/internal/service/qwen_media.go`、`backend/internal/handler/qwen_media.go`、`backend/internal/service/qwen_media_test.go`（13 测试）。
- 修改 `backend/internal/server/routes/gateway.go`（3 个 switch 各加 Qwen 分支）。

## 排障：qwen 生图 503 "Service temporarily unavailable"

- 凯哥 curl `/v1/images/generations`（qwen 分组）收到 503 api_error。定位：该文案唯一出处是 `no_account_error.go` classifyNoAccountError 的 fallback = **分组内没有可调度的该平台账号**（池空→503；池有账号但 model_mapping 不含该模型→404 model_not_found；生图开关关→403）。三者在文案上可区分，以后秒判。
- 结论：配置问题不是代码问题——分组加 qwen 账号（platform=qwen, type=api_key, active+schedulable, model_mapping 留空或含目标模型）。
- 参数差异（凯哥请求体是即梦风格）：DashScope 万相 size 用像素 `1024*1024` 不是 "2K"；`output_format` 字段转换时丢弃（万相无此参数）。未知字段不报错、静默丢弃，上游不认的参数由上游 400。
