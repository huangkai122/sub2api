## 任务：了解 sub2api 项目 + 生成后台配置账号池操作手册

凯哥要求先了解项目、再产出"后台配置账号池"操作手册。

### 关键结论（代码核实）
- **账号池概念**：概念层"上游账号集合"，物理实体 = `accounts` 表 + `groups` 分组（`account_groups` 中间表，含每账号每分组 priority）。
- **易混淆点**：界面"池模式(pool_mode)" ≠ 账号池本身，它是 **OpenAI / API Key 类型账号的上游错误重试开关**（同账号原地重试，默认 3 次≤10，状态码默认 [401,403,429]）。
- **账号类型(oneof)**：`oauth` / `setup-token` / `apikey` / `upstream` / `bedrock` / `service_account`；凭据结构在 `credentials` JSONB 内随类型变化。
- **调度无单一下拉**：由 `priority`(越小越优先) + `load_factor` + `concurrency` + `schedulable` + 全局开关(`openai_advanced_scheduler_enabled`/`stickyWeightedEnabled`) + 分组 `model_routing` + 粘性会话(session_hash/previous_response_id/Anthropic session_window) 组合。通用网关：优先级优先+同优先级随机打散；OpenAI：TopK 加权三层。
- 官方推荐实施顺序（PROJECT_FUNCTIONAL_DOCUMENT 第14节）：先建账号→建分组绑账号→签Key验证。
